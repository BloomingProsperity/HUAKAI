# 文件冲突锁

当前目标按一个执行者、一个计划、一个分支、一个 PR 推进，不使用自动派发、后台 worker 或双计划。旧派发文档、循环脚本和任务入口已经删除。

本目录只保留未来多执行者并行时所需的最小文件冲突锁：

- `check.sh`：查看当前锁或检查指定文件。
- `claim.sh`：声明将要编辑的文件。
- `release.sh`：完成编辑后释放锁。

单执行者工作无需创建锁。只有 Owner 明确恢复多执行者并行后，才按现行规则启用这些命令；历史任务与活动记录不构成有效计划或执行指令。现行规则见：

- [`AGENTS.md`](../AGENTS.md)
- [`docs/RULES.md`](../docs/RULES.md)
