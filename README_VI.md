Hiện tại nội dung chính chỉ có trong [README.md tiếng Anh](README.md) và
[README_CN.md tiếng Trung](README_CN.md). Phiên bản tiếng Việt đầy đủ đang
được chuẩn bị.

Để tham khảo nhanh:

- HUAKAI là một reverse proxy + account router tự host cho các tài khoản LLM
  API (Anthropic / OpenAI / Vertex / Bedrock / OpenRouter).
- HUAKAI **không** liên kết với bất kỳ nhà cung cấp LLM nào.
- Operator tự chịu trách nhiệm về việc tuân thủ Terms of Service của từng
  nhà cung cấp upstream và pháp luật áp dụng.

Vui lòng đọc [README.md](README.md) và [LEGAL.md](LEGAL.md) trước khi sử dụng.
