### 注册页 
- 来源:**new-api+sub2** · 后端:✅有 · 前端:🟡部分 · flags:`captcha`,`money-gated(优惠码赠额/推广分销)`,`oauth`,`邀请码`,`需薄前端`,`需薄后端(优惠码校验+邮箱后缀白名单)`
- 要什么:
    - 邮箱+密码（含可见性切换、密码提示文案）+ 客户端校验（邮箱格式、邮箱后缀白名单、密码长度）

    - Turnstile 人机验证（按设置显隐）
    - 登录协议同意闸（同登录页，弹窗/勾选两模式）
    - 社交注册区（GitHub/Google/LinuxDo/微信/OIDC 按设置显隐，aff_code 透传）
    - 邮箱验证开启时：把注册数据暂存 sessionStorage 并跳转 /email-verify；否则直接注册成功跳仪表盘
    - 站点名注入欢迎语、已有账号跳登录链接
    - 用户名 + 密码 + 确认密码三栏(密码 8-20 位,前端 zod 校验)
    - 邮箱验证(状态开关 email_verification 开启时):邮箱栏 + 验证码栏 + 发送验证码按钮(带倒计时防刷、需先过 Turnstile)
    - Turnstile 人机验证
    - 推广/affiliate 码:从 URL 的 aff 参数读取并随注册提交

### 登录页 
- 来源:**new-api+sub2** · 后端:✅有 · 前端:🟡部分 · flags:`captcha`,`needs薄后端(captcha provider/登录协议公开设置已部分有)`,`oauth`,`需薄前端`
- 要什么:
    - 邮箱+密码输入，含明文/密文切换眼睛、客户端校验（邮箱格式、密码长度≥6）
    - 提交后调用登录接口，成功后按 query 里的 redirect 跳回原目标页（默认仪表盘）
    - 2FA 编排：后端判定需二次验证时弹出 TOTP 验证码弹窗，输入 6 位码完成第二步登录（带遮罩邮箱提示、错误回显、可取消）
    - Cloudflare Turnstile 人机验证小组件（按公开设置开关显示），验证 token 随登录提交，失败/过期自动重置
    - 社交登录区：GitHub/Google（邮箱式 OAuth 按钮）、LinuxDo、钉钉、微信、OIDC（provider 名可自定义），各自按公开设置项独立显隐
    - 登录协议同意闸：可配置弹窗或勾选两种模式，未同意则禁用全部登录与快捷登录、按修订号记忆已同意状态
    - 忘记密码链接（仅当后端开启密码重置且非 backend-only 模式时显示）、注册页跳转链接
    - 进站读取一次性 public-settings 决定上面所有开关；会话过期标记会提示需重新登录
    - backend-only 模式下隐藏注册/忘记密码入口
    - 用户名或邮箱 + 密码两栏 + 提交登录;失败由全局拦截器提示
    - 登录成功若后端要求两步验证,跳转 OTP 验证码页
    - 依据后端公开状态决定是否显示密码登录区(password_login_enabled 可整体关闭密码登录)
    - Cloudflare Turnstile 人机验证(状态开关控制,token 随登录请求带上)
    - 通行密钥(Passkey/WebAuthn)登录按钮:浏览器能力探测、调用 navigator.credentials、begin/finish 两步握手
