## 验收重点

- 运营决策信息优先：状态、可用/不可用拆分、最后活动与可追踪下钻必须与施工图一致。
- 快捷入口只导航，不在首页直接执行危险动作。
- 部件失败相互隔离；页面不能因单端点失败整体消失，也不能把错误伪装成 0。
- 图形不仅“有形状”，还需有可访问名称、稳定 viewBox、真实图例与中心总量。
- 表格复用同一组件，但待办与审计的列定义、徽标语义和行操作分别由调用方提供。
