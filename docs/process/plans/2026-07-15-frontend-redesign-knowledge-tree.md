## 0. 前端架构与重做范围(设计者必读)

**技术栈(保留,勿换)**:React 18 + Vite + TypeScript 单页应用(SPA);`go:embed` 打包进单个 Go 二进制(sub2 单文件部署模式);数据层 `lib/api` 统一请求 + `tokenForPath` 三态鉴权。

**保留**:技术栈 + ~11k 行 API 数据层(功能接线、类型契约、鉴权)。**抛弃重做**:所有页面的视觉/布局/组件外观 + 设计系统。

**重做核心 = 建专业设计系统**:反克隆——**不照搬 one-api/参考项目的 6 个默认 token(色/圆角/阴影/字体/图标/间距)**;要一套自有的、专业的、三套壳统一的设计语言。Owner 两拒"一眼像抄袭",克隆味在 token 不在布局。

**三套 UI 壳(按登录身份切换,共用设计系统)**:
- **用户门户**(session token):终端客户自助
- **系统部署者运营台**(admin token):超管上帝视角
- **二级管理员**(分销商 token):分销商固定自助(独立第三套壳,分销 arc)

**四条贯穿设计原则**:
1. **反克隆专业感**:自有设计 token,不抄参考项目外壳。
2. **小白友好 · Hermes 内联解释**:报错/账号方块/日志条目旁放通用小 Hermes 按钮,点击用大白话解释错误出处/含义/怎么办(纯只读诊断)。目标用户多是小白。
3. **复杂设置聚合单页分区**:相关设置聚合(tab/折叠),别散页到处跳。
4. **配置 vs 操作分离**:系统设置放"配"(参数/开关),各功能页放"用/管"。

## 1. 用户门户(客户,session token)

### 概览
- **首页/概览**:余额、今日用量、快捷入口;**展示"已支持厂商"**(部署者上架了哪些 LLM 厂商就亮哪些牌子,自动跟随后台)。

### 我的账户
- **我的密钥**:API Key 列表/新建/吊销/用量;绑定分组。
- **个人资料与安全**:资料、密码、2FA、passkey、第三方登录绑定。
- **站内信**:收到的通知/广播。
- **安全日志**:本人登录/Key 操作审计。

### 用量与计费
- **使用记录**:逐笔调用明细(模型/token/成本/时间)+ 趋势图/分布图/导出(对齐 sub2 报表)。
- **钱包与充值**:余额、充值(兑换码兑换 / 在线支付入口 / 我的订单)。
- **订阅套餐**:可买套餐、我的订阅、用量进度。
- **分组与倍率**:所属分组、对应倍率、可换组资格。

### 活动中心(新)
- **每日签到**:签到得余额(金额部署者配),连签展示。
- **邀请返利**:邀请码、已邀请、返的余额。
- **推广**:推广素材/链接。

### 更多(开发与工具)
- **接入指引**:各协议接入示例(base_url/key)。
- **在线调试台**:playground 发请求试模型。
- **媒体任务**:图像/视频异步任务。
- **可用渠道**:本人可用的模型/渠道清单。
- **信任验证**:证明请求走的真号真模型(不掺水)。

## 2. 系统部署者运营台(超管,admin token)

### 概览
- **运营概览**:平台关键指标(用户/账号/用量/收入/健康),快捷入口。

### 网关资源(13→4 融合)
- **上游与模型**(融合大页,tab 分区):
  - ①**上游账号**:加账号(各厂商接入:OAuth 账号转 API / 官方 apikey)、列表、启停、**健康状态列 + 手动体检**、**刷新凭证(单个/批量)**、每账号选出口代理。
  - ②**厂商同步**:一键拉官方模型清单 + 上游目录(原始清单仓库)。
  - ③**模型字典**:模型主体 CRUD(canonical_id/协议族/上下文窗口/别名/能力/上下架),数字 id 清单(消除手输)。
- **账号池**:模型→池绑定、权重/并发/兜底、模型→账号强制 pin。
- **分组管理**(含路由+限速):用户组/账号组、组倍率、**该组用户→模型模式→目标池的路由规则**、**按组限速默认**。
- **IP 代理**:代理线路清单(名/协议/host/port/账密/状态)、每账号选线、不配=原始 IP 直出。(TLS 指纹后端默认开、无页。)

### 用户与财务
- **用户管理**(列表页→详情页):列表/建/删/封解封/解锁;详情=余额调整(加/减)、余额历史、用量明细、改组、安全操作(关2FA/清passkey/解绑)、**按用户/按key限速**。
- **使用记录**:全局逐笔台账(哪个真号/请求模型vs实际模型 证不掺水)+ 趋势报表 + 导出。
- **订阅管理**:套餐 CRUD、订户、用量进度、手动/批量指派。
- **按量付费定价**:**官方价×倍率**——输入输出价倍率窗口 + **缓存价独立倍率窗口**(各默认 1.0=官方价);全局/按组/按模型覆盖。
- **充值中心**(admin 配置聚合):配收款方式(实时收款/自动支付渠道)+ 发卡(兑换码生成:单张/批量/吊销/批次)+ 看账。
- **经销商**(分销管理):分销商列表/建站/停用/设批发价/划账号(上帝视角);分销商自己登录=独立第三套壳。

### 运维监控面板(参考 sub2 Dashboard,只显紧急)
- **一屏态势**:实时流量(QPS/TPS)+ 并发 + 账号可用性 + 系统资源(CPU/内存/磁盘)+ **检测台**(攻击态势:被扫/爆破/渗透探测/封IP)+ 告警。
- **三层降噪显示规则**(见 security-monitoring 方案):①同类去重聚合 ②按影响面分级(单账号429=个例不上盘/多账号429=系统性黄/池全线+触钱线+探针挂=红置顶)③出错(出站上游错)vs 被攻击(入站同源高频)分开标色。

### 日志模块面板(全量明细,审计级)
- **所有日志**:运行日志 + 错误/上游错误 + 攻击行为 + **审计操作日志**(谁干了啥);可搜/可导/按类tab。
- **结算重试队列**(原死信队列):扣费结算失败自动重试队列(正常应空)。
- **资金对账**(原孤儿对账):扫"预扣了但请求崩了、既没结算也没释放"的挂空钱,释放/补偿。

### 安全(细节:拦截规则)
- **内容审核**:审核配置 + **拦截规则(部署者可加:违规词/渗透攻击特征词/测试拦截)**+ 命中日志 + 违规自动封key/解封 + 违规哈希库。

### 设置
- **系统设置**(聚合配置中心,5 分区):①登录与注册(注册开关/验证码/密码策略)②第三方登录(各家 OAuth 配置)③**法律与合规(服务条款/隐私政策 Markdown + 登录强制同意 + 更新重新同意)**④邮件(SMTP + 邮件模板编辑器)⑤全局参数(签到金额/返利开关/限速默认/预算/配额探测/媒体参数/外部审核API开关)。(Relay 运行调优隐藏内置、env 后门无 UI。)
- **平台凭证**(易懂化):admin token + 平台 API key 管理(大白话说明+高级折叠)。
- **Hermes**(A 全暴露,4 区):①启停+身份(启停/api_source/绑profile/默认模型)②功能总开关(改动闸/工具循环/**LLM提议高危Owner-gated**)③**23工具权限矩阵**(名/作用/只读或改动/角色/可提议)④安全设界(并发/限流/巡检/保留期)。**扩展:每日巡检主动邮件(危险/被攻击/封号/中断四类)+ 报错旁内联解释按钮**。
- **公告管理**:平台通告墙(所有人可见,含未生效/已过期)。
- **站内信广播**:群发私信给全体用户。

## 3. 二级管理员 · 分销商 UI(分销商 token,独立第三套壳)

分销 arc(codex Slice1 建表已提交,Phase 逐期推进)。**一套固定自助功能集,全 scope 锁自己子树**:
- **概览**:自己的批发余额、下级数、用量。
- **下级用户管理**:建/管自己的下级用户。
- **下级发 Key / 分子额度**。
- **零售定价**:设自己的零售倍率(须≥批发地板,批发价碰不到)。
- **透明数据**:只看自己那摊真实数据(真号脱敏成「上游#N」/真模型/真并发/真用量,证不掺水);看不到别家、平台、下级对话内容。
- **公告**:平台子域用平台公告 / 白牌用自己公告(Phase 3 开关)。
- **禁**:碰批发价、看改凭证、加平台权、操作别家子树(安全硬门:防注入/IDOR/提权)。
