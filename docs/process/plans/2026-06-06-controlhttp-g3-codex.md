| Owner directive | "7 个 *http 处理器包 合成 1 个 internal/controlhttp(去碎片 G3, 行为零改变)" |
| Scope | In: merge eligible Go files and tests from `internal/panelauthhttp`, `internal/platformsettingshttp`, `internal/routeadminhttp`, `internal/modelhttp`, `internal/disputehttp`, `internal/twofahttp`, and `internal/notify/notifyhttp` into `backend/internal/controlhttp`; update `cmd/gateway` imports and call sites; remove emptied source directories. | Success criteria | For every merged package, non-test imports are reconfirmed as `cmd/gateway` only; package compiles as `controlhttp`; generic exported and unexported collisions are domain-prefixed or deduplicated without behavior changes; requested build, vet, and targeted tests are run with results recorded. |
| Time estimate | 60-90 minutes wall clock, mostly mechanical move/rename plus compile-driven collision cleanup. |
| Blast radius | Backend compile graph, `cmd/gateway` route wiring, and the moved handler package tests. No runtime behavior should change because handler code, route registration order, SQL calls, and response logic are preserved. |
| Failure modes | Importer is not unique: skip that package and report. Symbol collision is ambiguous: skip the package or prefix conservatively if local references are clear. Mechanical move loses tests: verify with `find`, `git diff --stat`, and `go test`. Route call-site rename breaks gateway wiring: catch with `go build ./...` and targeted `cmd/gateway` tests. |
| Decision points | Stop for Owner confirmation only if a package has non-`cmd/gateway` production importers, a collision cannot be resolved without changing behavior, a frozen package would need modification, or verification exposes a non-sandbox production behavior change. |

Inventory `.go` and `_test.go` files before move. 5. Create `internal/controlhttp` outside frozen packages. 6. Run gofmt, build, vet, and targeted tests from `backend` with `/usr/local/go/bin/go` and `GOCACHE=/tmp/go-build`. |
| Concrete execution order | 1. Run exact `git grep -l` importer checks for all seven packages. 2. Move eligible files into `backend/internal/controlhttp` with domain-prefixed filenames. 3. Change package declarations to `controlhttp`. 4. Update `cmd/gateway` imports and call sites to `controlhttp`, applying required exported renames. 5. Compile to discover same-package collisions. 6. Resolve collisions by domain prefixing local helpers/types or deduplicating only byte-identical helpers. 7. Remove emptied directories. 8. Run requested verification gates and report merged/skipped packages, rename map, package-count change, gate results, risks, and no behavior shrinkage. |
