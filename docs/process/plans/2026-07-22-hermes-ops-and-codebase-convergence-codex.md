## 一、已经核实的真相

1. 当前 `/v1/hermes` 可通过环境变量恢复普通用户 API Key 入口，与 Owner 的“三身份里普通用户绝不开放 Hermes”定性冲突，必须物理删除该回退路径。
2. 当前管理入口要求 `tenant_id` 和 `as_user_id` 查询参数。平台管理员可指定任意租户，并把操作伪装成租户里的某个普通用户。这既违反部署者不可越级操作下级租户的规则，也污染日志归属。
3. 当前设置、配置、会话和日志表以普通用户为所有者；管理员只是额外挂一个可空令牌字段。这个旧数据模型是错误根因，不能继续靠假用户补丁维持。
4. 当前 runner 固定在 `hermes-agent==0.14.0`，直接导入官方内部类并猜测方法参数；工具目录和执行器也是假定官方内部接口存在。该方式不是稳定的官方合同。
5. 官方 `hermes-agent==0.19.0` 提供正式命令行、MCP 和工具配置。可以关闭全部内建工具，只注册 HUAKAI MCP，让官方 Hermes 负责推理循环、HUAKAI 负责所有真实系统操作。
6. 当前工具执行主干已有只读诊断、提议、人工确认、原子变更日志、租户限定、并发与速率保护等可复用能力；但 `InputSchema` 只是说明文字，不是 MCP JSON Schema，工具重名也会静默覆盖。
7. 当前内部工具回调依赖进程内会话绑定，并要求管理员令牌 ID 大于零，导致管理员会话通道不能完整使用；多副本网关也可能把回调落到没有绑定的副本。
8. 当前公开 API Key 鉴权没有按 `api_keys.purpose='user'` 过滤。Hermes 的内部服务凭据若复用该表，必须先封死公开入口的用途混用。
9. 当前 runner 只出现在开发编排，暴露宿主机端口并持久化官方工作目录；生产和直连编排没有受控 runner，也没有完整资源、网络和文件系统隔离。
10. 当前 deadcode 与 staticcheck 基线均为 0，质量门同时检查默认、完整标签和视频标签三种构建形态的不可达符号交集；`gatewayhttp` 与 `proto` 仍超过代码预算，必须继续按职责缩小，不能借扩大基线逃避。

## 二、最终合同

### 2.1 人与权限

1. 系统只保留三种人：部署者、下级租户管理员、普通用户。Hermes 不增加第四种人类角色。
2. 部署者只在平台租户内使用 Hermes，不能借 Hermes 进入下级租户。
3. 下级租户管理员只在自己的租户内使用 Hermes，并且必须获得部署者授予的 `hermes_operations` 能力；默认无授权即拒绝。
4. 普通用户没有 Hermes 路由、页面、凭据、身份模拟或间接工具入口。
5. runner 使用内部服务主体，不代表某个普通用户，也不出现在普通用户管理面。

### 2.2 官方 Hermes 与 HUAKAI 的边界

1. 使用官方 `hermes-agent[mcp]==0.19.0` 的正式命令行或公开入口，不复制、改写或依赖其内部类。
2. 官方内建的 shell、进程、文件、浏览器、代码执行、技能、记忆、定时任务、更新和插件能力全部关闭。
3. 官方 Hermes 只看到一个 HUAKAI MCP 服务。MCP 仅提供 HUAKAI 已注册、已授权的只读工具和可提议工具。
4. 模型不能直接确认或执行变更。可逆操作只能生成一次性提议；管理员必须通过独立的 HUAKAI 确认端点提交。
5. HUAKAI 是会话、日志、授权、工具与恢复的事实源；模型调用由官方 Hermes 按其标准合同执行，官方工作目录按请求临时生成，用完销毁。

### 2.3 模型调用与费用

1. 部署者和每个获授权租户管理员分别配置自己的 OpenAI 兼容 `Base URL + API Key + 模型`；URL 与 Key 可以来自任意有效兼容服务，不要求属于 HUAKAI，也不要求专用 Key。
2. 配置按租户独立保存，API Key 使用租户绑定的 AES-256-GCM 信封加密；读取接口只返回 URL、模型与 Key 掩码，绝不返回明文、密文、nonce 或 key_id。
3. 每次聊天由网关在内存中解密当前租户配置，传给受控 runner 的一次性工作目录；请求结束即销毁。配置缺失或解密失败即拒绝，不回退到其它租户或平台默认配置；模型协议、请求错误和重试由官方 Hermes 标准实现处理。
4. 外部模型调用不伪造 HUAKAI 账号池、余额或 billing claim。若 URL 指向 HUAKAI，调用自然按该 Key 进入 HUAKAI 正式用户链；若指向外部服务，则费用由该外部服务结算。
5. 模型 API Key 只用于模型接口，不能作为 MCP 凭据。MCP 继续使用 HUAKAI 签发的短时、租户与真实管理员绑定令牌，保证模型供应商和 runner 都不能扩大数据权限。
6. 内部会话服务凭据使用独立用途，公开用户鉴权必须严格过滤用途，防止内部凭据被拿到公开端点使用。

### 2.4 运行与运维

1. runner 默认关闭，显式配置后才启动；单实例默认并发 1，有队列上限、请求超时、输出上限和熔断开关。
2. runner 无数据库、无 Docker socket、无宿主机目录；仅保留调用管理员明确配置模型服务和 HUAKAI MCP 的网络需求。
3. 容器使用只读根文件系统、非 root、删除全部 Linux capability、禁止提权，并配置 CPU、内存、进程数和临时盘上限。
4. 最低建议 2 核 2 至 4 GB；生产建议 4 核 4 至 8 GB。无需 GPU。多并发通过增加隔离 runner 副本扩展，不在单容器内无限并发。
5. 所有 Hermes 行为归入全局“日志系统”：操作、安全、错误、访问、恢复和费用分类明确；普通日志保留 30 天自动清理，费用账本真相按永久合同保留。

1. 新增收敛迁移，不修改已执行的旧迁移：

   - 给公开 API Key 与内部用途加数据库约束和查询过滤。
2. 重写 Hermes 管理鉴权：平台管理员固定平台租户；租户管理员固定作用域租户并校验能力；删除 `tenant_id`、`as_user_id` 和普通用户回退。

### 批次 B：完整网关模型链

1. 建立租户级外部模型配置：URL、模型、加密 Key、Key 指纹、最后验证结果与更新时间；所有写入都与分类日志同事务。

3. runner 请求把“外部模型 URL + 一次性解密 Key”和“HUAKAI MCP 短时令牌”拆成两个凭据域；官方 Hermes 配置只在请求临时目录生成并在结束后销毁。
4. 不制造 HUAKAI 余额与账单事实；URL 指向 HUAKAI 时，由公开入口自行生成真实 claim、usage、billing event 和恢复证据。
5. 补租户跨读、管理员越级、配置解密失败、临时文件清理和官方 Hermes 调用 MCP 的测试；模型协议错误遵从官方 Hermes 标准合同，不在 HUAKAI 再造一套分类或代理。

### 批次 C：MCP 唯一工具面

1. 把工具参数合同改为真正 JSON Schema，并在注册时验证名称、分类、执行函数和 schema；重名直接启动失败。

3. 只读调用直接执行并写分类日志；可逆变更只生成提议；危险或不可逆工具不向模型暴露。
4. 删除旧的假 `tool_catalog`/`tool_executor` 注入协议和重复工具目录实现，能力并集保留在唯一 registry。
5. 逐个工具测试成功、参数错误、角色不足、跨租户、重复注册、依赖缺失、日志失败和确认重放。

## 四、失败模式与防护

| 失败模式 | 防护 |
| --- | --- |
| 管理员跨租户读取或执行 | 租户从认证身份推导，不接收请求目标租户；平台与下级租户分别固定；每个工具和 SQL 再做租户条件 |
| 普通用户间接触达 Hermes | 删除用户路由和回退开关；公开 Key 查询过滤用途；内部服务凭据不能走公开解析器 |
| 官方升级后工具面扩大 | 全部内建工具禁用；启动时读取实际工具表并与单一 allowlist 比对，不一致不就绪 |
| 模型直接修改系统 | MCP 不暴露确认执行；模型只能读或生成一次性提议；确认端点要求真实管理员重新授权 |
| 外部模型调用被误算成 HUAKAI 费用 | 不生成虚假 claim；只有实际进入 HUAKAI 公开入口的 Key 调用才走正式余额与账单链 |
| 模型供应商故障被重复解释 | Hermes 官方处理模型协议、错误与重试；HUAKAI 只呈现 Hermes 会话和工具层结果，不再建立平行模型错误分类 |
| 模型 Key 被拿来调用 MCP | runner 分离模型 Key 与 MCP 短时令牌；MCP 只接受 HUAKAI 签名且绑定租户、管理员和请求的令牌 |
| 多副本会话绑定丢失 | 把短期授权状态做成可验证的自包含令牌或共享一次性存储；不依赖单进程粘性 |
| runner 失控或资源耗尽 | 无公网、最小网络、并发 1、队列/时间/输出/CPU/内存/PID 上限、只读文件系统和总开关 |
| 日志失败导致无证操作 | 变更继续保持业务写和日志同事务；只读日志失败显式计数和告警，不静默伪装成功 |
| 清理死码误删活入口 | 定义、构造、路由、反射/生成、测试与部署入口全部核实；先测试转红证明，再删除，再全量回归 |
| 大包拆分引入循环依赖 | 先抽无反向依赖的类型和服务叶子包；handler 只依赖窄接口；每次小批次保持可编译 |
