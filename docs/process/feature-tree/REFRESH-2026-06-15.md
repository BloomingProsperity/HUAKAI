## Engineering follow-up (test hygiene)

The full-line `integration_pg` suite is **not re-runnable on a persistent DB**: the
`internal/provider` vault tests use fixed tenant-name suffixes (`uq_tenants_name`
collisions on re-run), and `internal/tenancy` bootstrap deletes the default tenant 1
which other packages pollute with provider rows (FK 23503). Workaround in use:
`migrate drop -f && migrate up` before each full run gives a clean 217-ok pass; each
suspect package also passes in isolation. Recommended fix: unique per-test tenant
names + cascade-safe teardown so the safety net runs repeatedly without a DB reset.
