## 结论

W1 没有发现必须回滚或阻塞 closeout 的 reference parity 缺口。HUAKAI 已覆盖请求路径的提前刷新、同账号刷新去重、DB 版本竞争保护、refresh token rotation 保存与指纹审计：请求进入刷新前先查缓存，临期才刷新；同账号刷新拿锁，锁未拿到则短等待同伴结果；写回时带版本条件，竞争失败改用胜出凭据；上游返回新 refresh token 时保存并记录新旧指纹（HUAKAI:backend/internal/auth/antigravity_token_provider.go:141-232, HUAKAI:backend/internal/db/auth/auth_credentials.sql.go:150-188）。

## 升级点

`UPG-W1-001` OAuth refresh SSRF-safe dialing 是 HUAKAI 的主要升级点。CLIProxyAPI Antigravity refresh 使用 proxy-aware client 并保留代理配置后请求固定 Google token endpoint；sub2api Antigravity client 也接受代理并用普通 HTTP client 调 token endpoint，本次读到的 OAuth refresh 路径未观察到 resolve-validate-pin、特殊地址 denylist、禁代理和禁 redirect 的组合（CLIProxyAPI:internal/runtime/executor/antigravity_executor.go:226-238, CLIProxyAPI:internal/runtime/executor/antigravity_executor.go:1721-1731, sub2api:backend/internal/pkg/antigravity/client.go:261-285, sub2api:backend/internal/pkg/antigravity/client.go:367-407）。HUAKAI W1 对 endpoint 先要求 HTTPS，再在拨号层解析、校验、固定目标 IP，禁用 proxy/custom TLS dial hook/redirect，并拒绝 private、loopback、link-local、multicast、CGNAT 与特殊用途网段（HUAKAI:backend/internal/auth/antigravity_token_provider.go:340-440, HUAKAI:backend/internal/auth/antigravity_token_provider.go:455-487）。维度：架构 / 算法。

`UPG-W1-002` OAuth error redaction 也是明确升级。CLIProxyAPI 和 sub2api 对 token exchange/refresh 非 2xx 响应会把响应 body 或 body 摘要放进错误；本次读到的对应 refresh 路径未观察到统一 secret redaction + body_class 分类（CLIProxyAPI:internal/auth/antigravity/auth.go:162-171, CLIProxyAPI:internal/runtime/executor/antigravity_executor.go:1746-1753, sub2api:backend/internal/pkg/antigravity/client.go:397-399）。HUAKAI W1 把 OAuth 错误分为空体/非 2xx 摘要/截断态，先截断再走 token、JWT、org、vendor token、JSON/form secret redaction，并把安全文本写入审计和日志（HUAKAI:backend/internal/auth/antigravity_token_provider.go:348-360, HUAKAI:backend/internal/auth/sanitizer.go:11-35, HUAKAI:backend/internal/auth/antigravity_token_provider.go:547-555）。维度：算法 / 生态。

`UPG-W1-003` tenant-scoped audit verify 是生态级升级。本次 scoped search 对 `tenant_scope` / `Merkle` / request-id chain proof 等关键词在 CLIProxyAPI、sub2api、new-api 未返回对应用户可验证 trust-chain 模块；读到的 reference 命中主要落在 request signature、payment/operator audit 或参数改写审计，不能视为等价能力。HUAKAI W1 要求 caller 提供 request_id 与 tenant_scope_ref，按 request+tenant scope 取证，返回 hop/model chain、prev/root、签名和 key fingerprint，并校验签名及 key 有效窗口（HUAKAI:backend/internal/gatewayhttp/audit_verify_handler.go:92-127, HUAKAI:backend/internal/gatewayhttp/audit_verify_handler.go:250-299, HUAKAI:backend/internal/auditledger/ledger.go:94-150, HUAKAI:backend/internal/auditledger/ledger.go:190-214, HUAKAI:backend/internal/auditledger/canonical.go:23-64）。维度：架构 / 生态。
