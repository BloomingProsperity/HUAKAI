# 项目目标说明

项目目标是做一个 MIT clean-room 的 AI Gateway + Account Hub + Admin Ops Platform。

它需要覆盖：

- 多供应商 AI 网关。
- 账号和密钥管理中心。
- 渠道、路由、模型别名和协议转换。
- 配额、计费、用量统计。
- 管理后台和运营排障。
- 安全、审计、日志、健康检查、故障转移。
- 插件和功能开关。

目标不是“做一个简化版”，而是和 Sub2API、New API、All API Hub 等参考项目达到功能对齐或更强。
