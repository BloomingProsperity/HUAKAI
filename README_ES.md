Resumen breve:

- HUAKAI es un reverse proxy + account router auto-alojado para cuentas de
  proveedores de LLM API (Anthropic / OpenAI / Vertex / Bedrock / OpenRouter).
- HUAKAI **no** está afiliado con ningún proveedor de LLM.
- El operador es el único responsable del cumplimiento de los Términos de
  Servicio de cada proveedor upstream y de la ley aplicable.

Por favor lee [README.md](README.md) y [LEGAL.md](LEGAL.md) antes de usar.
